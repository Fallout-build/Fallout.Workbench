# Contributing

## Add an item

1. Pick the folder: `patterns/`, `antipatterns/`, `skills/`, `agents/`, `commands/` or `templates/`.
2. Start from the matching file in `templates/`.
3. Set `status: draft` in the frontmatter.
4. Open a PR. Keep it to one item.

## Maturity

| Status | Meaning |
|---|---|
| `draft` | Proposed. Not yet used in a real repo. |
| `trial` | In use in at least one Fallout-build repo. Feedback welcome. |
| `standard` | Used in several repos and stable. Safe to depend on. |

Promote an item with a PR that links the repos and PRs where it was used.

## Rules

- Keep items generic to the org. Repo-specific guidance stays in that repo.
- Write in plain English (see `skills/plain-english/SKILL.md`).
- Do not include secrets, private URLs or customer data.
